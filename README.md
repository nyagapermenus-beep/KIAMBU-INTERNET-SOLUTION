# NetPulse: Network Traffic Monitoring System for Kiambu Internet Solutions

## Project Overview
Developed as a partial fulfillment for the award of Diploma in Software Engineering at **Zetech University**.
- **Student:** Permenus Nyaga (DSE-02-0224/2025)
- **Project Domain:** Network Management & Cybersecurity / Web Application Development

## System Objectives
1. **SO1 (Database & Devices):** Manage and store network device records in MySQL.
2. **SO2 (SNMP Polling & Dashboard):** Real-time bandwidth tracking, traffic trend charts, and status monitoring.
3. **SO3 (Search & Reporting):** Historical record retrieval and traffic reporting.
